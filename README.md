# learning-bb

Independent bug-bounty lessons. Each numbered folder has its own lecture,
exercise, target where useful, and proof script.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd 02-xss
python app.py                 # terminal 1
python solve.py               # terminal 2
```

Lessons `00-01` cover workflow; `02-17` mirror the book's vulnerability track;
`18-21` cover expert techniques; `22-26` add important modern web topics.
