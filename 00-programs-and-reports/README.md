# Programs and reports

Learn scope, exclusions, rate limits, test-account rules, severity, triage, and
disclosure. Compare three public programs in a matrix. Then write a mock report:
title, asset, prerequisites, steps, minimal proof, observed impact, severity,
root-cause fix, and regression test. Name the missing invariant.

## Why this matters

Bug bounty work is constrained hypothesis testing. Program rules define which
product boundaries may be tested and which impact the owner values. A real
primitive outside scope or without product consequence is not a useful result.

## Exercises

Compare three public programs by exact assets, exclusions, account requirements,
automation limits, prohibited impact, payout table, and disclosure terms. Propose
three feature-specific boundary hypotheses for each. Then report one local case
using a normal control, one changed variable, resulting state, preconditions,
root cause, and regression test. Separate observation from inference.
